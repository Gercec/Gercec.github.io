ВВЕДЕНИЕ
Актуальность темы. В современных образовательных учреждениях, таких как Физтех-колледж, динамичность учебного процесса требует оперативного доступа к актуальному расписанию занятий. Классические методы информирования (бумажные стенды, скачивание и просмотр громоздких документов Excel) нередко неудобны для повседневного использования на мобильных устройствах, не позволяют быстро отслеживать текущий статус пары в реальном времени и вызывают сложности при смене семестров или курсов. Разработка специализированного, адаптивного веб-приложения «Расписание-ФизТех» с интуитивно понятным интерфейсом и автоматическим отслеживанием статуса уроков решает проблему оперативного информирования студентов и преподавателей.
Проблема заключается в отсутствии удобного, адаптированного под мобильные устройства и работающего в реальном времени веб-интерфейса для удобного просмотра расписания занятий и промежуточной аттестации студентов Физтех-колледжа.
Объект исследования: процесс информационного обеспечения и организации учебного расписания в профессиональном образовательном учреждении.
Предмет исследования: разработка клиентского веб-приложения для отображения и мониторинга учебного расписания и сессии в реальном времени.
Цель проекта: разработать и реализовать интерактивное веб-приложение «Расписание-ФизТех» (в формате единого документа index.html) для удобного просмотра расписания пар и экзаменационной сессии с автоматическим определением текущего статуса занятий.
Для достижения поставленной цели необходимо решить следующие задачи:
Проанализировать структуру исходных данных расписания (форматы Excel .xlsx и Word .docx).
Проектировать и реализовать пользовательский интерфейс веб-приложения в стиле Nothing OS / Pixel Art.
Реализовать парсинг и динамическую обработку расписания на стороне клиента с помощью JavaScript и внешних библиотек (xlsx.js, mammoth.js).
Разработать алгоритм отслеживания времени в реальном времени и цветовой индикации статуса пар (идет урок, перерыв, урок завершен, урок предстоит).
Реализовать интерактивные модули переключения семестров, курсов, групп и интерактивный блок уведомления о промежуточной аттестации.
Протестировать корректность работы приложения на различных устройствах и разместить исходный код в открытом репозитории GitHub.
Методы разработки и исследования:
Анализ требований и структур данных расписания;
Веб-разработка с использованием HTML5, CSS3 и JavaScript (Vanilla JS);
Использование сторонних библиотек для клиентоского парсинга документов (xlsx.js для документов Excel и mammoth.js для .docx);
Тестирование интерфейса на адаптивность и кроссбраузерность.
Практическая значимость проекта заключается в создании готового к эксплуатации веб-сервиса, которым могут ежедневно пользоваться студенты и преподаватели Физтех-колледжа для быстрого просмотра расписания со смартфонов и ПК без необходимости скачивания исходных файлов файлов Excel и Word.
